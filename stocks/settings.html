Comma separated, up to 8. Examples: ^GSPC (S&P 500), ^DJI (Dow), ^IXIC (Nasdaq), ^RUT (Russell 2000), AAPL, BTC-USD, GC=F (gold). Add a custom label with "=", e.g. MSFT=Microsoft. If an index isn't on your plan, its ETF (SPY, DIA, ONEQ, IWM) is shown instead.
Market data comes from Twelve Data. Get a free API key there and save it as TWELVE_DATA_API_KEY on the API Keys page. The free plan allows 800 requests a day, about one refresh every 15 minutes with 8 tickers.
